# GitHub Homepage Style v1.0.0

把个人GitHub首页布局整理成可安装、可修改的Codex技能项目。首版提供：

- 技能入口和允许按任务自动选用的UI元数据。
- 中文与完整英文首页模板，稳定导航锚点及可选章节。
- 布局规范与念景v0.2.1基准案例，案例链接固定到公开提交。
- 双语项目介绍、安装指南、两张原创SVG主图及MIT许可。
- 无第三方依赖的项目检查脚本及GitHub自动检查。

下载包包含`github-homepage-style/`技能目录和文件摘要，不包含个人Codex设置、记忆或念景媒体。调用技能需要Codex；模板本身也可以手动复用。

The first release turns a personal GitHub homepage layout into an installable, editable Codex skill. It includes Chinese and English templates, layout guidance, a pinned Nianjing example, installation instructions, original SVG artwork and package checks.

The downloadable package contains the skill directory and a checksum manifest. Personal Codex settings, memory and Nianjing media are excluded. Codex is required to execute the skill; the Markdown templates can also be reused manually.
