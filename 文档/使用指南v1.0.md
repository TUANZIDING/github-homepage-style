# 安装与使用 v1.0

本项目发布一个Codex技能。安装的是`skills/github-homepage-style/`目录，不是整个GitHub仓库，也不是作者电脑上的全局配置。

## 让Codex安装

在Codex发送：

```text
安装 https://github.com/TUANZIDING/github-homepage-style/tree/main/skills/github-homepage-style 里的技能。
```

安装后在下一轮对话调用`$github-homepage-style`。已有同名技能时，应先比较版本和已有修改；不要自动覆盖。

## 手动安装

下载[Release技能包](https://github.com/TUANZIDING/github-homepage-style/releases/latest)，解压，把`github-homepage-style`目录复制到自己的Codex技能目录。

默认技能目录为`~/.codex/skills/`；设置了`CODEX_HOME`时使用该目录下的`skills/`。保留`SKILL.md`、`agents/`、`assets/`和`references/`的相对位置。

也可以从项目源码复制：

```sh
git clone https://github.com/TUANZIDING/github-homepage-style.git
cd github-homepage-style
skillRoot="${CODEX_HOME:-$HOME/.codex}/skills"
mkdir -p "$skillRoot"
if [ -e "$skillRoot/github-homepage-style" ]; then
  printf '%s\n' '已有同名技能，请先比较版本并保留自己的修改。'
else
  cp -R skills/github-homepage-style "$skillRoot/"
fi
```

## 在仓库中使用

打开目标项目，让Codex读取已有文件，再发送：

```text
使用 $github-homepage-style 整理这个仓库的首页。
默认中文，另做完整英文首页。
沿用主图、居中标题、导航、成果、快速开始和能力说明的结构。
保留项目实际功能与命令，图片和配色按项目内容调整。
```

可以只做局部修改，比如“保持现有首页结构，只完善快速开始和英文入口”。模板变量需要替换，没有图库、API或运行界面的项目可以删除相关模块。

## 选择是否设为默认

可在自己的Codex全局`AGENTS.md`中写入：

```text
整理GitHub仓库首页时，默认使用 github-homepage-style 技能。
沿用结构，具体图片、配色与模块按项目调整；当前明确要求优先。
```

这是使用者自选的设置。安装技能不自动改写全局规则，也不授权公开发布仓库。

## 查看与检查

- [布局规范](../skills/github-homepage-style/references/布局规范v1.0.md)：章节顺序与视觉原则。
- [中文模板](../skills/github-homepage-style/assets/中文首页模板v1.0.md)和[英文模板](../skills/github-homepage-style/assets/英文首页模板v1.0.md)：可复制的骨架。
- [念景案例](../skills/github-homepage-style/references/念景首页基准v0.2.1.md)：结构来源，不是可直接替换项目名称的通用模板。

项目检查命令：`python3 验证/项目检查v1.0.py`。检查技能引用、摘要、语言导航、文档与图片路径、SVG格式和公开包中的本机路径。模板内的占位变量是有意保留的；实际交付的README不应留下占位变量。

只有GitHub内容核对完成时，不应声称浏览器视觉复核已完成。该项目也不验证其他仓库的业务功能或科研结果。
